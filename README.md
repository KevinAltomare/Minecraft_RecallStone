# Minecraft_RecallStone
Recall Stone – Fabric Mod for Minecraft 26.3
This mod adds a Recall Stone, a single‑use teleportation item that returns the player to their current respawn point. It’s implemented using the newest Fabric API and Yarn mappings, including the updated 26.3 item registry system and the rewritten respawn configuration API.
The project demonstrates:

Fabric mod initialization and item registration

ResourceKey‑based item IDs

ServerPlayer respawn config handling

Cross‑dimension teleportation

Custom item model + texture asset pipeline

Debugging and adapting to breaking API changes in Minecraft 26.3
Created as a fun side project to explore modern Java modding, game systems, and asset workflows.
