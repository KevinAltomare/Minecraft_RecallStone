# Minecraft_RecallStone
## Recall Stone – Fabric Mod (Minecraft 26.3)
Lightweight Fabric mod that adds a single‑use teleportation item designed for quick escapes and convenient travel. When activated, the stone instantly returns the player to their current respawn point — beds, respawn anchors, or the default world spawn.

The mod is built for Minecraft 26.3, using the updated item registry system and the rewritten respawn configuration API introduced in this version.

## Features
Instant Teleportation  
Returns the player to their active respawn point with a single use.

Cross‑Dimension Support  
Teleports safely between dimensions using the new global respawn position system.

Modern Fabric API Integration  
Uses the updated 26.3 item registration pipeline and respawn config handling.

Custom Item Assets  
Includes a unique item texture and model.

Usage
Right‑click with the Recall Stone to immediately teleport to your respawn point.
The item is consumed on use.

## Installation
Install Fabric Loader (26.3+).

Install Fabric API compatible with 26.3.

Place the mod JAR into your mods/ folder.

## Compatibility
Minecraft 26.3

Fabric API
